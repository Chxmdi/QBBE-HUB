namespaced `PRD-v2`; do not map them to similarly named master-brief IDs.

`blocked`. Existing code is not proof of acceptance. Each row starts awaiting
verification until a feature inspection establishes the remaining implementation.

result and artifact. All workstream dependencies must be verified before final
readiness. See execution-journal.md for active work and readiness-report.md for
